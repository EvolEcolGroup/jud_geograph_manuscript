# Data

## raw/

**`hgdp/Fst_pairwise.csv`** – Pairwise FST matrix for HGDP populations

- Square CSV matrix (populations × populations)
- Values range 0 (identical) to 1 (completely differentiated)
- Source: Human Genome Diversity Project (Rosenberg et al. 2002)

## intermediate/

Generated by analysis scripts. Not version-controlled.

**`hgdp_worldwide/`** – Outputs from s01
- Distance matrices (great-circle, land LCP, FST)
- Mantel test results
- Subset gData object (49 populations)

**`hgdp_asia/`** – Outputs from s02
- Graph objects (plain hexagonal grid, elevation, optimized)
- Distance matrices and Mantel test results
- Ruggedness threshold sweep profile
- Subset gData object (23 populations)

Regenerate by running scripts in `code/`.
